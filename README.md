# 漫游个人作品集

这个 Skill 能将你的经历、图片和项目链接，制作成一个可以自由探索的三维个人作品集网站。

建议跟简历配合使用：让简历讲清楚你的经历，让作品集展示需要看图、互动或亲自体验的项目。

## 做出来的网站长什么样？

你可以在场景中走动、探索，也可以自由切换森林、沙滩和浅海三种风景。

| 森林 | 沙滩 | 浅海 |
|---|---|---|
| ![森林主题](docs/images/forest.png) | ![沙滩主题](docs/images/desert.png) | ![浅海主题](docs/images/ocean.png) |

打开每一个小模块，就能查看对应的图片、文字和项目链接。你可以替换成自己的内容：科研经历、社团与志愿者经历、自媒体作品，或是实习与工作中的项目，都可以放进来。

![打开模块，查看对应内容](docs/images/content.png)

## 安装

复制下面这段口令，发送给你的 Agent：

```text
请安装这个 Skill，并按照它的流程帮我制作个人作品集：
https://github.com/panggungunvibe/island-portfolio
```
