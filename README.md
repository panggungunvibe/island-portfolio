# 漫游个人作品集

让简历用文字讲清你的经历，让作品集展示那些需要看图、互动或亲自体验才能理解的项目。

![森林里的个人作品集](docs/images/forest.png)

## 在风景中，打开你的作品集

这是一个由森林、沙洲和浅海构成的三维互动网站。来访者可以在其中走动、探索，逐渐打开你的个人作品集，也可以切换风景，换一种心情继续浏览。

| 沙洲 | 浅海 |
|---|---|
| ![沙洲主题](docs/images/desert.png) | ![浅海主题](docs/images/ocean.png) |

## 放进你想展示的一切

科研经历、社团与志愿者经历、自媒体作品，或是实习与工作中参与的大项目，都可以放在这里。

这个 Skill 开放了内容入口：你可以决定展示哪些经历，提供图片、链接和文字，再按照它的流程制作自己的作品集。保留的是这套三维场景与互动展示效果，换上的是你的故事和作品。

![走近营地，展开作品](docs/images/content.png)
